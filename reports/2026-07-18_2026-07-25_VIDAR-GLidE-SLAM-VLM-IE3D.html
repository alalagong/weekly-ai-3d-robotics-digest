Executive Summary

几何基础模型正在进入 SLAM/VIO 系统，但可靠性来自“学习候选 + 显式几何约束”的混合结构。VIDAR 用 SVO+IMU 提供度量位姿和尺度，再接 Depth Anything 3 生成稠密几何；Robust VIO 让 SEA-RAFT 只负责密集立体候选与不确定性，后端仍用时序跟踪、几何验证和因子优化；VLM-IE3D 把 2D VLM token 与隐式/显式 3D 几何 token 拼接，而不是直接把 RGB 语义当作空间判断。

嵌入式、通信受限和事件相机场景继续推动“系统工程型”贡献。GLidE-SLAM 的贡献点是 OpenGL ES 3.1 compute shader 上的混合 indirect-direct tracking；SemCom 3D 把通信置信度传入 RANSAC/BA；NeoSLAM 用 ROS2/C++/htm.core 重写 RatSLAM 系系统，把原实现的吞吐和模块耦合问题显式拆开。这些工作更像可部署系统设计，不是单纯排行榜改进。

World model 与 embodied navigation 的共同趋势是显式持久状态。WorldWeaver 使用 world state registers 在多 agent 视频片段间传递状态；Sequential EQA 把同一场景连续问答作为评估协议，显示 2D occupancy memory 和 VLA hidden state 的瓶颈；GS-Agent 让 Manager/Entity/Render agents 在物理引擎循环中创建 4D 世界。但这一线的代码可验证性参差不齐，GS-Agent 仓库当前仅占位。

world modelmulti-agent videopersistent state		 Fig.2 WorldWeaver pipeline，已视觉确认。 多 agent 长视频生成/预测需要跨时间片保留世界状态；单纯拼接历史帧会出现记忆衰减、主体身份错乱和可控性不足。 引入 K 个 learnable world state registers，在 chunk 间持续更新；用 agent stats、BEV maps、scene text 监督状态；训练分三阶段：bidirectional pretraining、causal WSR rollout、self-forcing 长程生成。 WSR 把隐式视频上下文显式化为可传递 latent state，类似把 SLAM 的 map/state 思想引入 diffusion world model。数学上是 autoregressive latent state update 与多源状态监督。 论文报告在多 agent 视频生成质量、状态一致性和可控性指标上优于相关 baseline。Limitations 明确依赖额外 state supervision，且真实世界状态更复杂、不可直接获得。 对 embodied simulation 的启发是 world model 不应只记画面，还要维护对象/agent/地图状态。复现重点是状态标注成本和 rollout 稳定性。 arXiv HTML 全文级；已读 Abstract、Method、Training、Experiments、Limitations/Conclusion；系统图已下载并视觉确认。未检查代码。

Trends & Insights

1. Foundation geometry 的工程接口比模型名更重要

VIDAR、Robust VIO、VLM-IE3D、Event3R 的共同点是把学习模型输出包装成可被几何系统消费的接口：pose/scale、correspondence uncertainty、geometry tokens、event tokens。短期工程判断应优先看接口稳定性、误差传播和 failure detection，而不是只看单表 SOTA。

2. 持久状态成为 world model 与 embodied navigation 的核心约束

WorldWeaver 的 world state registers、Sequential EQA 的跨问题记忆评估、Persistent 3D Object Tokens 与 MemoGuard 都指向同一问题：智能体需要可更新、可审计、可遗忘的状态。隐式 hidden state 在长程任务中证据不足；显式 3D/对象/地图记忆更容易诊断。

3. 3DGS 从渲染表示继续向在线地图和物理世界扩展

本期 3DGS 条目覆盖 online continual splatting、topology-aware splats、zero-shot splats、compressed splats、GS-Agent 4D physical worlds。工程侧要把“能渲染”与“能定位、更新、规划、验证物理状态”区分开，尤其当仓库还未公开时。

4. 热闹但证据不足的方向

零样本 object navigation、VLM UAV navigation、开放词汇 3D map 和多 agent world model 都在升温，但多数本期只读到摘要级证据。它们适合作为 watchlist，不适合作为近期系统选型依据，除非后续能看到代码、评测协议和失败案例。
