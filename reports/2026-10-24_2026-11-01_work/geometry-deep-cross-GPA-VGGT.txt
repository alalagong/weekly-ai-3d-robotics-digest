Abstract Feed-forward geometry models such as VGGT recover camera parameters, depth maps, and point maps from one to hundreds of views in a single forward pass, making them powerful backbones for multi-view 3D perception. However, VGGT's global attention is quadratic in the number of frames and dominates end-to-end runtime on long sequences, which has motivated a range of training-free efficiency methods such as token merging. These methods, however, come with a drop in accuracy that makes them hard to use in place of VGGT. We propose GPA-VGGT, a training-free acceleration method that replaces global attention in early blocks with frame attention augmented by a shared cross-frame K/V set. In the remaining blocks, we merge only keys and values while preserving all queries, restore the attention mass of the tokens each merged key represents, and randomly project the matching metric to 128 dimensions to reduce matching cost. Across diverse multi-view geometry tasks, GPA-VGGT provides training-free acceleration at speedups comparable to prior work while preserving the information required for precise geometric estimation, retaining over 99% of VGGT's pose accuracy under AUC@3. Method Query-Preserving K/V Merging blocks 9–23 Every query attends to the merged key set and keeps its own output. Each merged key represents s_j tokens, so its logit gets +\log s_j. The result is exact when the keys in a group coincide. Pooled Cross-Frame Broadcast blocks 0–8 Each query sees its own frame's patches, the camera and register tokens of all frames, and content-adaptive pooled summaries of all frames. The shared set is built once per block, with no masks or per-frame copies. Sensitivity-Aware Core Blocks blocks 13–16 Middle blocks attend sharply to a few cross-view correspondences, and errors made there are amplified downstream. They are merged at ratio 0.2 instead of 0.9. The set is chosen without ground truth. Low-Dimensional Matching 128-d projection Matching scores only feed an argmax, so we compute them after a fixed 1024→128 Gaussian projection. Matching gets about 7–8× cheaper, and the groups stay similarity-based. Reconstruction Under Predicted Poses Pick a scene below and orbit both views together.
