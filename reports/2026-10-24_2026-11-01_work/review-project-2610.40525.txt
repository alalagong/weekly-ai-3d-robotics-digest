CrossWeave: Cross-Modal Scene and Instance Retrieval from Sparse 2D-3D Alignment CrossWeave: Cross-Modal Scene and Instance Retrieval from Sparse 2D-3D Alignment Advances in Neural Information Processing Systems (NeurIPS), 2026 Main Track Poster 📌 Aadith Warrier1, Gnana Prakash Punnavajhala1, Siddharth Tourani2, Muhammad Haris Khan3, Avinash Sharma4, Madhava Krishna1 1IIIT Hyderabad, India 2University of Heidelberg, Germany 3MBZUAI, UAE 4IIT Bombay, India arXiv Code NeurIPS Poster TL;DR Instead of whole scenes or objects, CrossWeave trains on patch-point correspondences, the smallest unit of alignment. As a result, a single model can flexibly encode scene and object level embeddings, and sets the state of the art on both benchmarks of cross-modal scene and instance retrieval. Abstract Cross-modal scene and instance retrieval aims to retrieve a corresponding 3D environment or object given query 2D images, serving as a foundational mechanism for spatial reasoning in robotics and AR/VR. Existing methods achieve this by learning alignment only at the level of whole scenes or objects, which provides no supervision for the fine-grained local structure within them. In this work, we show that supervision on a set of sparse 2D-3D correspondences, without scene- or instance-level contrastive objectives, is sufficient to train a single model for both scene- and instance-level retrieval. Specifically, we propose CrossWeave, a novel framework for cross-modal retrieval that learns sparse patch-point alignment, which alone outperforms existing methods. An optimal transport-based aggregator over the aligned features gives further gains by clustering structurally redundant regions, freeing descriptor capacity for semantically distinct local features. CrossWeave achieves state-of-the-art performance on both scene- and instance-level retrieval on ScanNet and 3RScan with a single model, whereas existing methods require separate models for each task. Our results suggest that whole-scene encoding is unnecessary for cross-modal retrieval and that sparse local correspondence supervision is a more effective and flexible alternative. Method Overview of CrossWeave. Top: training from sparse patch-point pairs. Bottom: the same model used for scene and instance retrieval at inference. CrossWeave learns cross-modal retrieval representations from sparse image patch-3D point correspondences rather than scene- or instance-level labels. Given calibrated RGB-D observations and a reconstructed 3D map, visible patch-point pairs are obtained by projecting 3D points into the image plane, filtering occluded points using rendered depth, quantizing valid pixels into DINOv2 patch tokens, and selecting a compact semantically diverse subset using feature-space farthest point sampling. Frozen encoders extract local patch and point features, which are projected by learnable projection matrices Wpatch and Wpoint into a shared embedding space. A shared SALAD aggregator then maps variable-sized sets of local features into fixed-dimensional descriptors. Training combines a local patch-point Lp2p contrastive loss with an aggregated image-point-cloud contrastive loss Li2pc, preserving fine-grained alignment while organizing local evidence into retrieval-ready descriptors. At inference, the same encoders and projection heads serve both tasks: SALAD descriptors are used for scene retrieval and mean-pooled local features for instance retrieval. Sparse local supervision. Training uses a compact, semantically diverse set of visible patch-point pairs instead of whole scenes, with no scene- or instance-level labels. Two contrastive losses. Lp2p aligns each image patch with its 3D point, and Li2pc aligns the SALAD-aggregated image and point-cloud descriptors. One model, two tasks. The same trained network handles both scene and instance retrieval, using SALAD descriptors for scenes and local features for instances. Cross-Modal Scene Retrieval CrossWeave outperforms all baselines on both datasets at every rank. On ScanNet it reaches 61.54 Top-1 recall, 21.16 points above CrossOver (Updated). Since CrossOver (Updated) uses the same Utonia backbone, this suggests that the gain comes from sparse patch-point supervision rather than a stronger 3D encoder. On 3RScan, Top-1 recall rises from 23.57 to 46.50. Cross-Modal Instance Retrieval Each query object is retrieved among the objects of its own scene. Top-k is computed within each scene and averaged over scenes; R@k% is the percentage of scenes in which at least k% of the objects are retrieved correctly at Top-1. The same single model gives the best instance retrieval: 78.77 Top-1 on ScanNet and 73.50 on 3RScan. The gap widens at stricter thresholds, with R@75% improving over CrossOver (Updated) by 18.27 points on ScanNet and 14.65 points on 3RScan. Additional Experiments Comparison with SceneGraphLoc Following the SceneGraphLoc protocol, each query image is ranked against N candidate scenes; Top-k is the percentage of queries with the correct scene in the top k. SceneGraphLoc relies on ground-truth scene graphs at inference, whereas CrossWeave needs only a single image and a raw point cloud. CrossWeave still matches it at Top-1 with 10 candidates and exceeds it at Top-5 and Top-10 for both pool sizes, trailing only at Top-1 with 50 candidates.
