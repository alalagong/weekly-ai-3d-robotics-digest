# Supplemental 分类阅读规范

## 目的与设计

读者先按研究问题浏览，用一句话判断相关性，遇到值得跟进的工作再展开方法、实验与证据。保留全部纳入条目；展示密度与检索完整性分别验收。

采用“分类目录 → 单篇一句话 → 单篇详情”三级结构。对比过分页表格（仍然需要横向读七列）和只列精选（无法交代完整跟踪集合），选择分类折叠，兼顾短首页与完整内容。

- 分类按论文主要研究问题，不能把命中查询名称当作研究方向。建议覆盖 SLAM/VIO、多视图与定位配准、几何基础模型/前馈3D、3DGS/神经重建、语义地图/空间理解、具身导航、世界模型/仿真、传感器/应用；允许按本期内容调整，避免超大“其他”筐。
- 每个 ID+版本只出现一个主分类；跨方向关系在详情中保留。分类显示真实数量，新文、期内修订、历史补漏、历史版本补跟踪分别标记/计数。
- 默认收起分类；展开后每篇显示标题、约40–100字的一句话、状态和证据标记。一句话优先写“解决什么问题 + 核心做法/差异”，不重复标题，不把摘要结论写成复现实测；必要限制可进入一句话。
- “优先关注”是基于与 SLAM/3D 主线的直接关系、方法新意、可复现入口或重要更新作出的编辑提示，不是全文深读或性能领先的认证。不得按固定篇数截断跟踪集合。
- 单篇详情使用原生 `details/summary`，包含问题、方法/结构、insight/数学、实验、实际证据、后续动作、原文与精确版本时间。摘要没有数字就保留“未提供”。Supplemental 不嵌图。
- 关键词搜索覆盖标题、ID、一句话及详情；支持时间归属筛选、仅优先关注、分类选择、重置，以及展开/收起分类。结果计数实时同步，零结果有明确提示。首次打开不藏掉任何条目；无 JavaScript 时仍能逐类/逐篇原生展开。
- 保留原 `paper-*` 锚点；带锚点访问时自动展开祖先分类和论文并定位。筛选后再点击站内论文锚点也须可见。
- 页面独立可用，无远程脚本、接口或 CDN。窄屏允许换行，不能依靠固定宽表格。

## 生成接口

模板使用 `SUPPLEMENTAL_CATEGORY_NAV` 与 `SUPPLEMENTAL_CATEGORY_GROUPS`，替代旧的 `SUPPLEMENTAL_PAPER_ROWS`。模板内已提供样式与筛选脚本，不要再次输出旧七列表格。

渲染器：`reports/templates/render_supplemental.py`。输入是标准 ledger，以及与跟踪 ID 集合一一对应的 presentation JSON：

```json
{"categories": [{"id": "slam-vio", "label": "SLAM / VIO / 多传感里程计", "description": "状态估计、动态鲁棒性与融合"}], "papers": [{"id": "arXiv基础ID", "category": "slam-vio", "takeaway": "一句话关键做法与适用边界。", "priority": true, "priority_reason": "与核心状态估计直接相关"}]}
```

渲染器检查集合完整、ID唯一、分类有效；现有报告重排时保留原单元格全部详情。不允许分类失败时默默省略条目。后续新报告可直接从 ledger 字段生成详情。没有合适分类时新增有含义的分类。
